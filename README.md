# Madabase

Independent buying research and five focused affiliate publications.

```bash
nvm use 20
npm install
npm run dev:main
npm run dev:affiliate
```

- `apps/main`: Madabase research and cross-site search.
- `apps/affiliate`: Homeoffice, Network, Smarthome, Baby and Pets.
