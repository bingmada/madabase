Markdown 常用于 README、技术文档、更新日志、博客草稿、客服说明和 GitHub issue。它写起来简单，但发布前用实时预览检查格式，可以避免标题、表格、代码块或列表渲染出错。

这个在线 Markdown 预览工具支持你输入或粘贴 Markdown，并即时查看渲染结果。它适合检查标题、代码块、链接、表格、任务列表、强调和嵌套列表。

当你只想快速预览 Markdown，而不想打开完整编辑器或登录其他平台时，可以直接使用这个页面。

[FAQ]
什么是 Markdown？
Markdown 是一种纯文本格式语法，用来表示标题、列表、链接、代码块、引用等常见文档结构。
什么是 Markdown 预览？
Markdown 预览会显示纯文本 Markdown 渲染成格式化 HTML 后的样子。
支持 GitHub 风格 Markdown 吗？
这个工具面向常见 GitHub Markdown 场景，例如 README、表格、任务列表和围栏代码块。
为什么我的表格没有正确显示？
表格需要表头行、分隔行和一致的管道符。缺少分隔行是最常见的问题。
我的 Markdown 会上传吗？
不会。预览过程在浏览器本地执行。
