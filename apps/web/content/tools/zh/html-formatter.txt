[INTRO]
从模板、生成代码、邮件布局或网页片段中复制 HTML 时，代码经常被压缩成一行或出现不一致的缩进，使嵌套元素难以追踪，也会让代码审查产生很多无意义差异。

这款在线 HTML 格式化工具使用统一的两空格风格，为完整文档或 HTML 片段添加缩进和换行。粘贴代码、执行格式化、检查结果，然后复制可读版本即可。

格式化只调整代码的呈现方式，不等于验证代码正确。它适合阅读和编辑，但不能保证有问题的 HTML 符合标准。格式化过程在浏览器内完成，你粘贴的 HTML 不会为了格式化而上传。

[FAQ]
HTML 格式化工具做什么？
HTML 格式化工具（也称为 HTML 美化器）获取混乱或压缩的 HTML 并添加适当的缩进和换行以使其可读和结构良好。

为什么要格式化 HTML？
格式化后的 HTML 更容易阅读、审查和维护。清晰缩进有助于发现嵌套关系和意外的结构变化。

这个工具使用什么缩进？
当前工具统一使用两空格风格，暂时不提供制表符或四空格选项。

可以格式化带 CSS 的内联 HTML 吗？
可以格式化带 style 属性和普通嵌套标签的 HTML。遇到框架模板或特殊嵌入语法时，请检查输出结果。

它会验证 HTML 吗？
不会。格式化与验证是两项不同工作。无效或不受支持的语法可能报错，但成功输出不代表文档一定符合 HTML 标准。

它会删除 HTML 注释吗？
不会。本工具用于美化代码，不负责压缩 HTML 或删除注释。

内联 JavaScript 会怎样？
工具会整理外围 HTML，但嵌入代码和模板语法有各自的解析规则。替换生产代码前请检查输出。

我的 HTML 代码会上传吗？
不会。所有格式化都在浏览器本地进行。你的代码永远不会离开你的设备。
