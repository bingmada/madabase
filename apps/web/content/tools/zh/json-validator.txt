在线校验 JSON 语法，检查缺少逗号、尾随逗号、引号、括号和无效 JSON 结构。输入内容在浏览器本地处理。
[INTRO]
JSON 校验是排查 API 响应、配置文件、Webhook 数据和复制数据问题的最快方式之一。一个缺失的逗号或多余的尾随逗号，就可能导致整段请求失败。

这个在线 JSON 校验器会检查输入是否为有效 JSON，并给出实用的语法提示。你可以在发送接口请求、保存配置、粘贴文档或对比 JSON 之前先验证数据。

如果你搜索的是 validar JSON online、JSON validator、JSON lint 或 validate JSON online，这个页面会先给出可直接使用的工具，再帮助你理解如何修复错误。

[EXAMPLES]
{"name":"Madabase","tools":3}
===
有效 JSON
---
{"name":"Madabase",}
===
无效 JSON：结束花括号前存在尾随逗号
---
{'name':'Madabase'}
===
无效 JSON：字符串和键名必须使用双引号
[FAQ]
JSON 校验器有什么用？
它会检查文本是否符合 JSON 语法规则，确认是否可以被解析为有效 JSON。
常见 JSON 错误有哪些？
常见错误包括尾随逗号、缺少逗号、单引号、键名未加引号、注释、undefined 值和括号未闭合。
JSON 可以使用单引号吗？
不可以。标准 JSON 的字符串和对象键名都必须使用双引号。
JSON 可以写注释吗？
标准 JSON 不允许注释。有些配置格式支持注释，但那不是标准 JSON。
JSON 校验器和 JSON 格式化工具有什么区别？
校验器检查 JSON 是否有效；格式化工具美化有效 JSON。实际调试中通常会两个一起用。
我的 JSON 会上传吗？
不会。校验过程在浏览器本地执行。
