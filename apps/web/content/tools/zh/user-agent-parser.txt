[INTRO]
User Agent 字符串会由浏览器、爬虫、机器人和各种 HTTP 客户端发送。它可以提供浏览器、操作系统、设备类别、渲染内核，以及请求是否可能来自自动化程序的线索。

这个在线 User Agent 解析器会把冗长的 User Agent 字符串转换成可读的 JSON 摘要。它适合排查 analytics、日志、重定向、移动端识别、浏览器兼容性和 bot 流量问题。

User Agent 解析只能作为线索。现代浏览器可能会减少或冻结部分 User Agent 信息，所以结果适合调试和路由判断，不适合做身份识别或安全决策。

[FAQ]
什么是 User Agent 字符串？
User Agent 是 HTTP 请求头中的一段文本，用来描述发起请求的客户端，例如浏览器、App、爬虫或机器人。
User Agent 能识别精确设备型号吗？
通常不能。它能提供移动端、平板、桌面、系统和浏览器线索，但精确设备识别并不可靠。
为什么 Chrome 和 Edge 的 User Agent 里也有 Safari？
很多浏览器为了兼容历史网站会保留兼容性标记。解析时要看完整字符串，不能只看单个词。
可以用它判断 bot 吗？
可以发现明显的 crawler、bot、spider 标记，但 User Agent 可以伪造，不能单独用于安全判断。
我的日志会上传吗？
不会。解析过程在浏览器本地执行。
