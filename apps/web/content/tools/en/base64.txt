[INTRO]
Base64 turns binary or Unicode text into an ASCII-safe string that can travel through JSON, URLs, emails, logs, and configuration files. Developers often search for a Base64 encoder when they need to prepare a payload, inspect an encoded API value, or decode a JWT header or payload.

This online Base64 encoder and decoder keeps the tool first: paste text, choose encode or decode, and copy the result. It is useful for quick debugging because you can compare plain text and encoded output without opening a terminal or writing a script.

Base64 is not encryption. Anyone can decode it. Use it for transport and representation, not for hiding secrets.
[HOW_TO_USE]
Paste text or Base64
Enter plain text to encode, or paste a Base64 string that you want to decode. UTF-8 text, Chinese characters, emoji, and common API values are supported.
---
Choose encode or decode
Use encode to convert readable text into Base64. Use decode to convert Base64 back into readable text when the input is valid text data.
---
Copy and verify
Copy the result into your API client, documentation, config file, or debugging note. If decoded output looks broken, the original value may be binary data or not valid Base64 text.

[FAQ]
What is Base64?
Base64 is a binary-to-text encoding format. It represents data with letters, numbers, plus, slash, and padding characters so the value can be stored or transmitted as text.
Is Base64 encryption?
No. Base64 is encoding, not encryption. It is reversible and should not be used to protect passwords, tokens, or private data.
Why does Base64 end with equals signs?
Equals signs are padding. They help the encoded string align to the expected byte grouping. Some URL-safe variants omit padding.
Can I decode JWT tokens with this page?
You can decode individual JWT header and payload segments. For a complete JWT view, use the JWT decoder linked from this page.
Why does decoded text look unreadable?
The Base64 value may represent binary data, compressed data, encrypted data, or a string using a different encoding. Not every Base64 value decodes into readable text.
Does this upload my input?
No. The conversion runs in your browser, so your input is processed locally.
