[FAQ]
What does a JSON validator do?
It checks whether text follows JSON syntax rules and can be parsed as valid JSON.
What are common JSON errors?
Common errors include trailing commas, missing commas, single quotes, unquoted keys, comments, undefined values, and unclosed brackets.
Can JSON use single quotes?
No. JSON strings and object keys must use double quotes.
Can JSON have comments?
Standard JSON does not allow comments. Some config formats allow comments, but they are not valid JSON.
What is the difference between JSON validator and JSON formatter?
A validator checks whether JSON is valid. A formatter beautifies valid JSON. Many workflows use both.
Does this upload my JSON?
No. Validation runs locally in your browser.
