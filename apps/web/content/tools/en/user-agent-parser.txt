[INTRO]
A user agent string is sent by browsers, bots, crawlers, and many HTTP clients. It can reveal useful hints about the browser, operating system, device class, rendering engine, and whether the request may be from automation.

This online user agent parser turns a long user agent string into a readable JSON summary. It is useful when debugging analytics, logs, redirects, mobile detection, browser compatibility reports, and bot traffic.

User agent parsing is always a best-effort hint. Modern browsers may reduce or freeze some user agent details, so use the result for debugging and routing clues rather than identity or security decisions.

[FAQ]
What is a user agent string?
A user agent string is an HTTP header value that describes the client making a request, such as a browser, app, crawler, or bot.
Can user agent parsing identify the exact device?
Not reliably. It can provide hints such as mobile, tablet, desktop, OS, and browser, but exact device identification is often incomplete.
Why do Chrome and Edge both include Safari in the user agent?
Many browsers include compatibility tokens for historical reasons. A parser must look at the whole string, not one token.
Can I use this for bot detection?
It can flag obvious crawler tokens, but user agents can be spoofed. Do not use user agent parsing alone for security decisions.
Does this tool upload my logs?
No. Parsing runs in your browser.
